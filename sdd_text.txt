The system is designed to implement Count All, Count On, and Number Bonds learning strategies through interactive gameplay mechanics, adaptive features, and learner progress monitoring to support engaging and personalized learning experiences.                                         Scope                 Add-Venture is a standalone Android mobile application designed using the MVVM architectural pattern to provide adaptive and interactive learning experiences for Grade 1 learners. The application implements Count All, Count On, and Number Bonds strategies through progression-based gameplay, adaptive learning mechanisms, guided hints, learner progress tracking, and performance monitoring features.                 The system design includes the following components and functionalities:                       Drag-and-drop quantity grouping activities                       Count All activities                       Count On activities                       Number Bonds activities                       Adaptive difficulty adjustment                       Guided hints and feedback                       Activity progression and unlocking                       Learner progress monitoring                       Performance summaries                       Local data persistence using Room and SQLite                  The application is intended for learners, teachers, and parents to support learning and monitor learner performance.                               Definitions and Acronyms                                                                         Term / Acronym                                          Definition                                                MATATAG Curriculum                                       The curriculum framework implemented by the Department of Education that focuses on strengthening foundational learning competencies.                                           Count All                                       An addition strategy where learners count all objects from the beginning to determine the total quantity.                                           Count On                                       An addition strategy where learners start from a known quantity and continue counting instead of restarting from one.                                           Number Bonds                                       A strategy showing part-whole relationships where smaller quantities combine to form a total quantity.                                           Adaptive Learning                                       A learning approach where task difficulty changes based on learner performance.                                           Performance Monitoring                                       Tracking learner metrics such as accuracy, response time, and recurring errors.                                           UAT                                       User Acceptance Testing; evaluation conducted to determine whether the system meets user needs and requirements.                                           MVP                                       Minimum Viable Product; the initial version containing the core system features.                                             UC                                  Use Case; a functional interaction scenario between user/system and application.                                              Activity Session                                   A single learner interaction period involving one or more addition activities.                                              Progression Criteria                                   Conditions required to unlock succeeding activities.                                              Adaptive Difficulty                                   Automatic adjustment of activity complexity based on learner performance.                                              Guided Hint                                   Visual or instructional support shown after incorrect responses.
